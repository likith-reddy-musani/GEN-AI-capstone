ROLE: Cybersecurity Engineer
ROLE_LABEL: Cybersecurity Engineer
TARGET_DOMAIN: Security Operations, Threat Modeling, Application Security, and Cloud Defense

CORE SKILLS REQUIRED:

- Network security & protocols: TCP/IP packet inspection, TLS/SSL handshake analysis, DNSSEC, IPSec
- Vulnerability assessment & penetration testing (VAPT): manual exploitation, scanning, remediation
- Application Security (AppSec): OWASP Top 10 web vulnerabilities (SQLi, XSS, SSRF, CSRF, IDOR)
- Cryptography fundamentals: symmetric/asymmetric encryption, hashing (SHA-256), HMAC, digital signatures
- Identity and Access Management (IAM): Role-Based Access Control (RBAC), ABAC, SAML 2.0, OAuth 2.0, OIDC
- Security Information and Event Management (SIEM): log ingestion, query formulation, alert tuning
- Endpoint Detection and Response (EDR): host telemetry analysis, behavioral anomaly detection, containment
- Incident response lifecycle: identification, containment, eradication, recovery, lessons learned
- Malware analysis basics: static disassembly, dynamic sandboxing, string extraction, IOC extraction
- Secure Software Development Lifecycle (SSDLC): integrating static and dynamic code gates into CI/CD
- Cloud security posture: least-privilege policies, security groups, VPC flow logs, cloud audit trails
- Zero Trust Architecture: micro-segmentation, continuous identity verification, software-defined perimeters
- Compliance & regulatory frameworks: NIST Cybersecurity Framework, CIS Controls, ISO 27001, SOC 2
- Forensic analysis: volatile memory capture, filesystem timelines, disk image acquisition, PCAP triage
